## 三、AI 起草风险点（法务重点 review）

| 风险 | 位置 | 备注 |
|---|---|---|
| "随时"权利表述可能太绝对 | 隐私政策 §四 | 法务可能要求 "30 天内" 等明确期限 |
| 飞书推送可能涉及境外节点 | 隐私政策 §三.4 | 法务需评估数据出境合规 |
| LLM 服务商（豆包 / 通义 / DeepSeek）共享范围 | 隐私政策 §七 | 实际传给 LLM 的内容字段需明示 |
| 7 天通知期的合法性 | 服务条款 §九 | 需符合《个人信息保护法》要求 |
| "未实名认证未成年人主动关停" | 隐私政策 §五 | 技术上无法识别，需说明边界 |
| 管辖法院条款 | 服务条款 §八 | 法务需根据公司注册地调整 |
