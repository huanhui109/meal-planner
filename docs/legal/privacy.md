## 一、我们收集的信息

### 1.1 账号信息（登录时）
- **微信小程序**：微信 `openid`、头像、昵称（仅在「微信一键登录」场景）
- **飞书机器人**：`open_id`、昵称、租户 ID（仅在飞书登录场景）
- **本地开发登录**（仅后端开启 `APP__AUTH__DEV_LOGIN=true` 时可用）：用户输入的昵称

> **说明**：你不需要授权以上全部登录方式，选用其中一种即可。账号信息仅用于身份识别，不用于画像或广告。

### 1.2 偏好信息（功能必需）
- 家庭人数 / 每日餐次 / 厨房设备
- 偏好菜系 / 辣度 / 口味 / 主食
- 过敏源 / 忌口食材 / 饮食习惯（如清真、素食）
- 健康目标（减脂/增肌/控糖等）/ 每日热量 / 三大营养素比例
- 每周预算上限 / 工作日 / 周末预算 / 外卖参考价

### 1.3 业务数据（功能必需）
- 冰箱库存：食材名称 / 数量 / 单位 / 保质期
- 菜单：周菜单 / 餐次 / 食材清单
- 自动化：飞书应用绑定状态 / 推送偏好

### 1.4 设备与日志
- 设备型号 / 操作系统 / 微信版本 / 网络类型
- 异常堆栈（崩溃自动上报）
- 关键操作埋点（登录、生成菜单、识别、换菜）

### 1.5 我们不收集
- 通讯录 / 地理位置 / 相册（仅在拍照识别场景临时读取照片，识别后立即释放）
- 设备唯一识别码（IMSI / MAC）

- 跨产品共享（除非你显式同意）

## 三、信息存储与保护

### 3.1 存储位置
- 服务器：阿里云华东 1（杭州）MySQL 主从 + Redis 缓存
- 备份：每日凌晨 03:00 异地备份，保留 30 天
- 小程序本地：仅存 access_token / refresh_token / 主题偏好 / 引导完成标记

### 3.2 加密
- 传输：全站 HTTPS（TLS 1.2+）
- 存储：密码 bcrypt 哈希 / 令牌 jose 签名 / 敏感字段 AES-256

### 3.3 访问控制
- 仅运维 + 开发负责人有数据库写权限
- 应用层 RBAC：用户只能读写自己的数据

### 3.4 跨境
- 默认不向境外传输
- 飞书推送：飞书自有协议，可能经过飞书国内节点

## 六、Cookie 与本地存储

- **小程序**：使用 `Taro.setStorageSync` 存 access_token / 主题偏好，不与第三方共享
- **H5**：使用 Cookie 存 access_token（HttpOnly + Secure），localStorage 存主题偏好
- **飞书机器人**：飞书自有 OAuth 体系，Token 由飞书管理

## 附录：术语表

- **openid**：用户在某一应用内的唯一标识，由平台（微信 / 飞书）颁发
- **access_token**：登录后的会话凭证，2 小时有效
- **refresh_token**：刷新 access_token 用的长期凭证，30 天有效
- **埋点**：记录用户行为用于产品改进，不含个人身份
